# Optional decision note

Routine Desktop Sentry work does not require a specification. Use this note only when
the user requests a durable document or a high-risk decision benefits from one.

- **Outcome:** What should become visibly true?
- **Decision:** What direction did the user choose after discussion?
- **Safety:** What data, compatibility, privacy, or rollback constraint matters?
- **Verification:** What focused evidence will show that it works?

Keep the note short. It supports the conversation; it does not replace the user's
meaning or create an additional approval process.
